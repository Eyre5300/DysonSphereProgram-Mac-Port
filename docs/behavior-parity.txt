Windows 原版行为对齐记录（持续更新，非完整验收报告）

修改准则
每个问题先核对同版本 Windows 输入的原始实现，再判断是否为移植缺陷。
优先修改平台输入、资源和图形适配层。保留原版按键、窗口关闭顺序、游戏规则、模型和功能。
无法对齐时记录原版行为、Mac 差异、原因、替代操作和验证范围，不以“基本可玩”代表完全一致。

已核对：航行输入与窗口规则
Caps Lock：默认曲速键；一次按下进入，再一次按下退出。松开不得触发新操作。
Tab：切换航行鼠标锁定/释放。
C：同时打开机甲信息和背包，再按 C 关闭。
Esc：按原版优先级逐层关闭。C 打开的窗口先关闭背包，再关闭机甲信息。
只有无窗口需要光标且航行锁定开启时才隐藏光标。主动 Tab 释放的状态应保留。
依据：该支持版本原始 VFInput、PlayerMove_Sail、UIGame、UICursor 的调用路径。
曾尝试一次 Esc 同时关闭两个窗口，因改变原版操作已撤回，未纳入公开转换流程。
Mac Caps Lock 已通过 GCKeyboard 物理按下事件接入原版曲速逻辑。用户确认两轮进入/退出正常；日志显示松开事件不增加按下次数。仅大小写/输入法状态变化的候选曾导致退出后重入，已弃用。
重新点击窗口后光标保留符合原版失焦释放逻辑；用户确认按 Tab 恢复正常。未修改为点击自动锁定。

1. Steam 服务集成禁用；不能宣称成就、云同步或其他 Steam 服务与 Windows 等效。
2. 新机器完整转换流程未验证；本机已完成自有输入的独立重建与部分功能回归。
3. 跨恒星物流已在独立世界验证两趟曲速运输、途中保存重载和返航；已在预置资源/框架下验证实际火箭/太阳帆发射、到达/吸收，以及自然地面敌人的炮塔战斗。大型网络、完整战斗、全资源建造链及长期稳定性尚未全面验收。

这些条目不是全部潜在问题的清单；每项实际修复都需要相应运行证据。

UI多重采样存储：仅四个已测试目标在AppleMetalMac使用临时MSAA存储；原版图像的自然帧/重复/负对照及初建、尺寸切换、保存重载通过。最大绝对RGBA差0.000488低于0.001阈值，未证明逐位完全一致；不改分辨率/颜色格式/深度/抗锯齿数、游戏规则或模型。银河界面及主相机不改。

分拣器光带：修正遗漏的原版 SOFTPARTICLES_ON 场景深度分支。原版 softParticles=1，普通箭头材质 ZMin=-0.3、ZMax=0、XRay=1；只看 ZTestOff 的旧分析不完整。当前按用户明确要求，普通已建分拣器的派生着色器另外使用严格 LEqual，让实体完全遮挡光带。这会取消原版约0.3游戏单位的背面容差，是已记录的显示差异；不改运输逻辑、材质色彩/动画/混合、模型、建造/蓝图预览。130/55MB副本各三视角、9统计页及科技/星图/戴森球/机甲/蓝图/背包、运行和保存重载通过；受控深度前/后/可见区域正反对照通过。截图中光带不再穿过伊卡洛斯和建筑；界面提示和部分时间驱动灯光仍变化，不作为逐像素一致声明。
