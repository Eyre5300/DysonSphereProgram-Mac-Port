Mac 迁移向导：用户操作指南（开发版）

iPad 用户请使用根目录 start-ipad.command，先读 ipad/MIGRATION.txt。
两端共用的完整 Steam 下载步骤见 docs/Steam游戏文件准备.txt（仓库根目录）。

本程序在本地把已购买的 Windows 游戏转换为 Apple Silicon Mac App，不提供游戏，不上传游戏，也不会请求你的密码。当前只支持 DSP 0.10.35.29104；其他版本会拒绝转换。

重要状态：转换脚本已经在开发机从原始 Windows 文件独立完成导出、修复和构建，带诊断的构建通过了两份旧存档、蓝图及菜单测试。普通 Release 首轮自检在帧末截图后立即保存触发 Metal 崩溃；已修正自检时序并通过保存重载及正常退出。这不是删减模型或效果的修复。目前仍是开发者预览，不能承诺他人在新机器生成后可直接稳定游玩。新机器全流程尚未验证。本页只描述 Mac 向导；iPad 已有独立连续迁移入口，状态见 ipad/VALIDATION.md。

第一次准备
先安装 Apple Command Line Tools（终端运行 xcode-select --install），或完成 Xcode 首次设置。向导检测不到 clang 时会提示安装，完成后回车继续。
1. 使用 Apple Silicon Mac，准备完整 Windows 游戏文件夹（DSPGAME.exe 所在目录），保持原文件不变。
2. 安装 Python 3.12：https://www.python.org/downloads/macos/
   在 port-tools 文件夹打开终端，运行：
   python3.12 -m venv ~/.dsp-port-venv
   ~/.dsp-port-venv/bin/python -m pip install -r requirements.txt
   若安装失败，先查看终端报错；没有完成安装前不要跳过检查。
3. 自行在 Unity Hub 安装 Unity 2022.3.62f3c1 和 Mac 构建支持，登录并激活适用许可。账号、资格确认和条款由本人完成。
4. 准备 AssetRipper 2.0.0、SPIRV-Cross、vkd3d 2.1。具体来源、提交版本、构建说明见 dependencies.txt。本版本向导不会自动安装这些工具，需要提供可执行文件路径。
5. 建议预留至少 50 GiB 工作空间（建议值，不是峰值保证），工作目录使用非云同步的本地磁盘。不要选 Steam 原始目录、OneDrive 存档目录或 port-tools 内部。

从 Mac 上的已购 Steam 获取 Windows 输入（无需运行 Windows 游戏）
先在 Steam 登录每位使用者自己的已购账号。在浏览器地址栏打开 steam://open/console，允许转交 Steam；在 Steam 控制台输入：
  download_depot 1366540 1366541 8688761953740169502
这是本项目已验证输入对应的 manifest；Steam 需允许当前已购账号取得该版本。等待 Depot download complete，再把该行显示的实际文件夹提供给向导。不要凭系统语言猜测路径；也不要提供 Mac Steam 应用本身。文件夹中应有 DSPGAME.exe、DSPGAME_Data 和 Locale 等完整目录。下载不同版本时，向导会按 Assembly-CSharp.dll 哈希拒绝，不能删去校验继续。也可从自己的 Windows 电脑复制同一完整版本。
程序只读取自有游戏并在新的私有目录处理；不读取或绑定 Steam 登录密码。生成游戏的 Steam 成就、云同步等服务目前没有接入。

启动
双击 port-tools/start.command；也可在终端运行：
~/.dsp-port-venv/bin/python wizard.py
这是终端交互程序，尚未包装成图形 App。
如果 macOS 要求允许打开，请自行核对本地工具的来源；程序不修改系统安全设置。

程序会告诉你做什么
• 缺 Python 库：给出对应安装命令，完成后按回车重新检查。
• 需要路径：输入路径，或把 Finder 中的文件/文件夹拖入终端。
• Unity 登录/许可：在 Unity Hub 完成后输入 done，程序再继续。
• 准备完成：显示输入/输出目录，输入 start 开始。
• 自动阶段：导出资源和代码副本 → 应用平台修复 → 恢复着色器 → 构建并检查错误 → 本地签名 → 可选原版纹理恢复。
• 如某阶段失败：保留日志，终端显示错误末尾和日志位置。先处理报错（如缺组件、许可过期、空间不足），再次启动同一向导继续。游戏/着色器修复错误通常需要开发者排查，不应盲目重复。

暂停和恢复
在提问处输入 q 暂停；下次运行相同命令可继续。构建时建议等待当前阶段完成，不要关闭 Unity。
默认进度：~/Library/Application Support/DSPPortConverter/session.json
日志：同目录 logs。
已成功的阶段不会重跑。prepare 中断时会要求输入 retry，把未完成目录改名保留后重新导出；失败的 App 会保留，新尝试使用新名字。着色器阶段复用已完成的提取缓存。
如果工具版本已改变，向导拒绝混用旧阶段。请用一个新进度文件和新的工作目录开始：
~/.dsp-port-venv/bin/python wizard.py --session ~/DSPPortSessions/new-run/session.json
不能直接改写已生成的游戏代码后声称转换工具可复现。

生成后
终端显示确切 App 路径。构建/签名通过只说明产物生成正确，不等于运行无 bug。
可选择 test 进行静音自检：先正常退出所有 DSP 实例，再在 Finder 启动程序所列 App。它新建独立世界、保存、重载，并尝试正常退出。正常退出可能更新游戏“最后退出”自动存档；手动命名存档不会被覆盖。完成后回到向导按回车检查结果；闪退时在向导输入 crash，卡住可以 q 暂停；都不能当作通过。
程序不会自动替你点击操作系统许可或验证界面。基础测试结果也不代表完整战斗、星际物流、戴森球建造或长时间稳定性。

分享
只分享 port-tools 中经过来源/许可审查的工具。不要分享 local-private、生成的 Assets/Assembly-CSharp/HLSL/游戏 DLL/App、个人存档或蓝图。每位使用者提供自己的游戏文件。转换工具本身不会上传用户文件。

航行操作沿用原版：Caps Lock 一次进入、再按一次退出曲速；Tab 切换鼠标锁定；C 打开/关闭机甲信息与背包；Esc 按顺序先关背包再关机甲窗口。切回软件窗口后，需按 Tab 恢复航行视角。
恢复向导会保留同一 App 已取得的自检结果；未绑定当前 App 的旧结果不作为通过依据。单纯修改说明文档不会要求重做已经完成的转换阶段。

自检结果会结合本次 Player.log：日志必须来自选择的 App，并包含正常退出标记。原生绘图跳过、着色器错误或本次时间范围内的系统崩溃报告会判为失败，不能仅凭保存/重载 JSON 显示通过。

编辑器预检：转换前读取Unity安装元数据，验证固定2022.3.62f3c1及MacStandaloneSupport。版本或组件错误时给出安装提示，可重新输入正确编辑器路径；不会先启动错误版本或自动接受许可。

恢复阶段的产物检查
- 重新运行时会核对已完成中间产物的 SHA-256；文件丢失或变化时重新生成，并使后续缓存失效。不会仅凭旧进度标记跳过。
- 若选定的 SPIRV-Cross 或 vkd3d 二进制被替换，恢复会停止并显示原因。恢复原先的工具，或使用新的会话和私有工作目录重新转换，避免混用不同编译器的产物。
- 旧格式仅记录脚本哈希的恢复检查点会重做一次相应阶段；旧游戏、存档和已有 App 保留。工具代码变化时向导要求新的会话，不混用旧阶段。
